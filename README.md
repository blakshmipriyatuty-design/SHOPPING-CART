### SHOPPING-CART
## Project Overview
A modern and user-friendly Shopping Cart application UI designed in Figma. It allows users to browse products, view product details, add items to the cart, complete checkout, and receive order confirmation.

## Objective
* Create a simple shopping cart design
* Make shopping easy for users
* Provide easy cart management
* Create a simple checkout process
* Make the interface user-friendly

## Design Highlights
1.Clean and modern interface

2.Simple navigation

3.Consistent Inter typography

4.Rounded cards and buttons

5.Clear product hierarchy

6.Easy-to-understand icons

7.Consistent color palette

8.Mobile-friendly layout

## Features
* Browse and search products
* View detailed product information
* Add and remove items from cart
* Adjust product quantities
* Simple checkout and payment
* Order confirmation and tracking
